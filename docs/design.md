# 产品与实现约定

## 用户流程

外部工具 → 选择难度 → 导入歌曲/已有包 → 可选高级设置 → 生成 ZIP → OpenSekai 社区版导入 → Live。
难度是采音模型条件，不保证对应官方定数；playLevel 默认为未知值 0。切换难度恢复该档采音预设，保留手动 BPM 和起点。

## 时间与文件

- 新歌曲先按原曲起点/长度裁剪，长度 0 表示余下全曲；再添加前置静音，默认 9 秒。
- 默认试听从音乐开始，即音频第 9 秒；高级设置试听起点相对于裁剪后的音乐。
- 手动节拍起点按原曲填写：实际值 = 原曲起点 − 裁剪起点 + 前置。
- SUS 时间相对音乐开始，导出只减一次前置，Live 只加一次前置。
- 谱面时长 = ceil(音频秒数 − fillerSec + 2)，沿用社区版结尾缓冲。
- 已有歌曲包重新生成不裁剪，不重复加静音，保留元信息、试听、封面和视频，另存新包。

## 发布与核验

每个任务独立保存请求、状态、诊断和暂存项目。核验实际 SUS 的网格、双指约束和连续视觉重叠，然后将实际 SUS 转为社区版 MusicScoreMakerData JSON。只有验证完整的项目才通过目录移动发布；已有目录不覆盖。

发布歌曲 ZIP 只包含玩家资产，诊断日志和原输入路径不进入歌曲包。Windows 支持选取 CustomMusicScores 目录追加导入；Android 通过系统文件选择器导出 ZIP，由游戏导入。

Windows 取消使用工作进程协议；手机在模型块和事件之间检查取消标志，不发布失败任务。手机切出界面由前台服务继续运行，进程被系统结束后不会自动续算。

## 平台与范围

Windows 界面调用打包的 AutoChart/OurSekai.Worker.exe，无安装 Python 的需求。Android 使用内置 Python 和 Java ONNX 桥接，独立离线生成。

本工具没有谱面编辑器。已安装的 OpenSekai 本体负责歌曲管理、Live、视频、成绩和配置，工具不会改写原游戏；原游戏编辑入口因此保留。原 Unity 集成原型留在工作目录供参考，不作为外部工具发布内容。

自动 BPM 的便携算法与桌面算法不同，不能要求所有歌曲结果逐点一致。质量和性能仍需多曲、全难度、长曲、手机断网与 Live 实测。
