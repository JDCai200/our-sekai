# 验证记录（2026-10-04）

## 0.2 模型和输出设置

600 首谱面，按歌曲互斥划分为 427 训练、86 验证、87 测试。236 个段落簇，每簇至少 20 个片段，实际至少 16 首源歌曲。独立长条模型由 46,730 条训练长条学习 64 类路径。单键、尾部键型和路径模型的测试概率损失均低于训练频率基线，详见训练报告。

两个真实歌曲片段按相同 NS 提案对照实际 SUS：单键 flick 3 → 32，critical 对象 0 → 35，长条尾 flick 0 → 5，带控制点长条 15 → 43，折返 17 → 72。变宽长条 7 → 4，尚未改善。实际谱面均通过双指、网格、连续视觉重叠核验，并被真实社区版程序集读取。

新版便携链已通过新歌、已有包音频字节保持和取消检查；DSP、分块循环状态和新模式森林概率对照通过。APK 编译、签名、11 项模型资产哈希和无网络权限检查通过。Windows 支持自选目录；Android 持久 SAF 文件夹授权、自动保存 ZIP 和升级模型缓存已实现，真机文件提供器和后台体验未验收。

Windows 新版成品已完成打包 GUI → 打包 worker → 自选输出目录 → 歌曲 ZIP 的真实生成检查：6 秒原曲输出 15 秒音频，前 9 秒全零，55 个结构点；任务与日志留在私有任务目录，歌曲和 ZIP 发布到选定目录。

## 未验证范围

没有连接的 Android 设备，尚未真机测试 JNI 推理、后台生命周期、长曲内存/耗时、触屏体验、断网生成和导入后的 Live/成绩。APK 可构建并通过静态验包不代表这些项目已经通过。

当前 Android 仅 ARM64、Android 7+、4 KB 内存页。16 KB 页设备不支持。当前调试签名用于预览，正式发布需自己的签名和手机验收。

Windows 已跑通打包程序的生成流程；独立无开发环境机器、交互界面、多曲/全难度、游戏 Live 音画同步与成绩仍未完整验收。
