# Our Sekai 配套工具

本工具配合已安装的 **OpenSekai 社区版** 使用，不包含游戏本体。
外部工具负责导入音频、选择难度、自动生成可游玩歌曲包；Live、成绩、视频和游戏设置仍由原游戏提供。
原游戏自己的编辑器保持原安装状态，本工具不提供谱面编辑。

## Windows

1. 完整解压发布 ZIP，保留 `OurSekai.exe`、`_internal/` 和 `AutoChart/` 的相对位置。
2. 双击 `OurSekai.exe`，先选 EASY / NORMAL / HARD / EXPERT / MASTER，再导入歌曲。
3. 点击“生成可游玩歌曲包”。默认实际添加 9 秒静音；原曲不会修改。
4. 在 OpenSekai 的歌曲管理中选择“导入”，导入生成的 ZIP。
   也可以点击“加入 OpenSekai 歌曲库”，选择游戏的 `CustomMusicScores` 目录，然后刷新歌曲列表。
5. 打开 OpenSekai，选择该歌曲进入 Live。

工具的设置、输出与任务日志位于 `%LOCALAPPDATA%/OurSekaiCompanion/`。
点击“设置输出位置”可选择歌曲目录和 ZIP 的自动输出文件夹；选择会保存到下次启动。任务日志仍保存在应用数据目录。手动“导出歌曲包”也可以另选保存位置。
参数集中在高级设置中，节拍起点按原曲填写，程序自动换算前置。
歌曲过短或节奏不明显时自动 BPM 可能失败；可以在高级设置填写 BPM。

“已有歌曲包”用于导入 ZIP 后另存生成一张新谱面：沿用已加前置的音频、试听、封面与视频。
直接在 OpenSekai 导入已有包不需要经过本工具，不会重复添加前置空白。

工具和模型随完整 Windows 发布包提供。玩家不需要 Python、Unity、服务器或联网推理。
歌曲包包含 `manifest.json`、`score.json`、音频、SUS，以及可选封面和视频，可传到社区版 Android 玩家端导入。

## Android

1. 安装 ARM64 APK；允许安装来自下载来源的应用。
2. 先设置难度，通过系统文件选择器导入歌曲或已有歌曲包。
3. 按需展开高级设置，然后点击生成。首次使用释放内置模型，不需要下载。
4. 等待完成，点击“保存 ZIP”选择保存位置。
5. 在已安装的 OpenSekai 社区版导入 ZIP，选择歌曲进入 Live。

手机独立完成离线分析与生成，不需要 Windows 或另装 Python。生成任务使用前台通知，可取消；失败时显示错误，不发布未通过核验的包。请为音频、模型和计算临时数据保留足够空间；长曲可能耗时较长。
可以点击“设置输出文件夹”，通过系统文件选择器授权一个目录。此后生成成功自动保存 ZIP，设置会持久保存；无权限或存储不可用时显示保存失败，应用私有目录中的已生成包仍保留，可重新选择目录后点击保存。未设置文件夹时，每次保存选择位置。

0.2 版首次生成会校验并更新内置模型缓存。键型与重音使用训练后的节奏条件概率，长条路径使用扩展模式库；实际导出仍必须通过可游玩核验。生成包含概率采样，相同音频与参数使用固定种子，可重复生成；不保证模拟官方难度定数。

当前为调试签名预览版，支持 Android 7+ ARM64、4 KB 内存页设备；不支持 16 KB 页设备。尚未完成手机真机测试，验证范围见 `docs/verification.md`。压缩音频取决于设备解码器，WAV 当前支持 PCM16。

## 对接范围

已确认的格式来自社区版基线 `0cd2e6212d71671d48373732fbaa3559c16a765a`。
原版 OpenSekai 或更早、不同分支不保证有同一歌曲包管理功能。
本工具不会覆盖游戏 EXE、DLL、APK、原歌曲或游戏成绩。
